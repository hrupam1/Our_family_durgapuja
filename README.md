# 🌺 Our Family Durga Puja

Welcome to the official website for **Our Family Durga Puja**. This is a beautiful, modern, and interactive web application built to celebrate the spirit, devotion, and togetherness of our family's annual Durga Puja festival.

## ✨ Features

- **Dynamic Schedule:** Track the auspicious timings for Mahalaya, Shashti, Saptami, Ashtami, Navami, and Dashami.
- **Puja Samagri Guidelines:** Detailed lists of essential items for various rituals like Bhog, Naivedya, Mahasnan, and Nabapatrika.
- **Events & Activities:** Explore our categorized events, including sacred Rituals, fun Games (like Musical Chairs, Conch Blowing, etc.), and Cultural Events.
- **Memories Gallery:** Take a walk down memory lane with yearly galleries capturing our favorite moments.
- **Smooth Animations:** Powered by Framer Motion, GSAP, and Lenis smooth scrolling for a premium user experience.
- **Responsive Design:** A fully responsive interface that looks stunning on mobile, tablet, and desktop devices.

## 🛠️ Tech Stack

This project is built using modern web technologies to ensure a fast, accessible, and beautiful experience.

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) & [GSAP](https://gsap.com/)
- **Smooth Scrolling:** [@studio-freight/lenis](https://github.com/darkroomengineering/lenis)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites

Make sure you have Node.js (v18+) and npm installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hrupam1/Our_family_durgapuja.git
   cd Our_family_durgapuja
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📁 Project Structure

- `/src/app` - Next.js App Router pages and layouts.
- `/src/components` - Reusable UI components (Navbar, Footer, Hero, Timeline, etc.).
- `/src/lib` - Utility functions (e.g., `cn` for Tailwind class merging).
- `/public` - Static assets like images and logos.
